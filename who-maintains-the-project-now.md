Zetacoin is maintained by EWMCI, LLC (East-West Magnate Cryptocurrency Experts), based in East Pennsylvania, USA, reachable at info@ewmci.com. The company took over stewardship after the 2018-2021 community period, rebuilt the chain in 2021 and maintains Zetacoin Wallet, whose current release is on the GitHub releases page.

## The short history, in order

Zetacoin launched on 3 August 2013 as a Bitcoin-derived SHA-256 coin with 30-second blocks and a 160 million cap. It was listed on the exchanges of the era, had an Android wallet built by a community developer, and appeared on German national television during the first wave of altcoin coverage.

The middle years were a handover rather than a stop. Through 2018 to 2021 the project moved from its original developers to community stewardship and then to EWMCI, which is the entity that commissioned the rebuild. In 2021 the chain moved to Scrypt with hybrid Proof-of-Work and Proof-of-Stake, and holders migrated one for one.

Since then the work has been maintenance and release: a Qt desktop client for three platforms, a bootstrap archive for faster syncing, documentation for configuration and mining, and an exchange page that reflects where ZET can actually be traded.

The full walk-through, with the checks in order, is in [What Is Zetacoin? The Scrypt Coin Behind the ZET Wallet](https://github.com/zetacoin-wallet/zetacoin-wallet-guides/blob/main/what-is-the-zet-coin.md).

Maintenance is not a claim about headcount. It is visible in artefacts: a release with notes, a repository with issues answered, documentation that tracks the current build. Those exist, which is what makes the question answerable at all.

## Why the old thread says nobody maintains the coin

Because it was written during the handover. The BitcoinTalk topic that began at launch contains years of posts, including the stretch when the original developers had stepped back and the new steward had not yet started shipping. A reader who lands on a 2019 page inside a 2013 thread is reading a moment, not a status.

The same is true of the repository README that still describes the retired chain: it documents the legacy software, so it describes the legacy situation. Neither is evidence about the current release.

The practical test is the release page. A coin with no maintainer does not publish builds, does not answer issues, and does not ship a client for three operating systems. {{ARTICLE:is-zetacoin-still-active-today}} covers the network signals that make the same point from the chain side.

For the background behind this step, [Is Zetacoin Still Active in 2026?](https://github.com/zetacoin-wallet/zetacoin-wallet-guides/blob/main/is-the-chain-still-active.md) covers the same ground in more detail.

## How many people work on it

The project does not publish a headcount, and inventing one would be worse than saying so. What can be stated is what is observable: a maintained client, a release cadence with notes, a documented support contact, and a company behind it with a registered presence.

For a chain of this size that is the normal shape. A 30-second hybrid chain with sub-0.1% annual inflation does not need a large team to keep producing blocks; it needs a client that works, a way to sync quickly, and documentation that answers the questions people actually ask.

What maintenance looks like in practice is worth spelling out, because it is the difference between a company name on a page and work being done. A release carries notes describing what changed and which toolchain versions still build. A bootstrap archive exists so that a new installation does not spend hours downloading chain state. The configuration file is documented, including the fee setting and the ports a node needs. When a distribution changes a library, the build instructions follow it.

None of that is glamorous, and none of it happens by itself. It is also the reason the client still installs on a current machine a decade after the coin launched, which is a more useful test of stewardship than any statement about intentions.

## Who owns Zetacoin

Nobody owns the network. ZET is a decentralised chain: coins are held by their owners, blocks are produced by miners and stakers running the software, and no company can move a balance or reverse a transaction.

EWMCI maintains the client and the project's public presence, which is a different thing from owning the coin. That distinction matters when someone claims a company can freeze, refund or recover funds  -  it cannot, and any message saying otherwise is a scam.

## Is the project reachable?

Yes. The project publishes a support address, runs community channels and keeps an issue tracker on the repository. For a wallet problem, the fastest route is usually the documentation and the release notes; for anything else, the contact address is the official channel.

Lookalike domains and accounts exist, so the rule is to start from the release page and the project's own site rather than from a search result. {{ARTICLE:where-to-download-official-zetacoin-wallet}} covers how to tell the official source from a copy, and {{ARTICLE:zetacoin-vs-zetachain-key-differences}} covers the name collision that produces most of the false leads.

## Common questions

### Who created Zetacoin?

It launched in August 2013 as a Bitcoin-derived coin. Development later passed to community stewardship and then to EWMCI, LLC, which rebuilt the chain in 2021 and maintains the wallet today.

### Does EWMCI own my coins?

No. ZET is held by whoever controls the keys, and no company can move a balance or reverse a transaction on the chain.

### Why does an old forum post contradict this?

It was written during the 2018-2021 handover, before EWMCI began shipping the rebuilt client. It describes that moment, not the current release.

### How do I contact the maintainers?

Use the contact address published by the project, or open an issue on the repository. Both lead to the same team.
