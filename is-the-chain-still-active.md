## What "active" means here, measured

Activity claims are worth little without something countable, so here is what can be checked from outside the project. The chain height rises, the gap between blocks stays in the minutes, both Proof-of-Work and Proof-of-Stake blocks appear in the same window, and peers answer on the network port.

| Signal | What to look for | What it means |
| --- | --- | --- |
| Block height | A number above 4.6 million, still climbing | The chain is producing, not frozen |
| Block spacing | Minutes, not days | Miners or stakers are online |
| Block types | Mixed PoW and PoS entries | Both consensus halves are working |
| Peer count | Around fourteen known peers | The network is reachable |
| Release page | A current build with notes | The client is maintained |
| Explorer | Height matching your wallet after sync | Your node agrees with the network |

None of these require trusting a marketing page. A synced wallet is itself the evidence: if your client reaches the same height as a public explorer, the chain exists and your software agrees with it.

The full walk-through, with the checks in order, is in [What Is Zetacoin? The Scrypt Coin Behind the ZET Wallet](https://github.com/zetacoin-wallet/zetacoin-wallet-guides/blob/main/what-is-the-zet-coin.md).

## Why some sites still call it inactive

Aggregators copy each other. A listing written during the quiet years carries an "offline" or "inactive" label forward through database merges, and nobody re-checks it, so the label outlives the fact by years.

The 2018-2021 period was a transition, not an ending: community stewardship, then EWMCI taking over development, then the 2021 rebuild that moved the coin from SHA-256 to Scrypt. A page written in the middle of that process described a pause in visible activity. It cannot describe the chain as it runs now, because the chain it was describing no longer exists in that form.

When a third-party page and a synced node disagree about whether blocks are being produced, the node wins. That is the whole test.

## What actually changed since 2018

The coin did not stay still, which is part of why old descriptions read as stale. The consensus moved to hybrid Proof-of-Work and Proof-of-Stake, the hashing algorithm moved from SHA-256 to Scrypt, the supply was rebuilt around a 1:1 migration, and the address format changed from a `Z` prefix to a `9` prefix.

The economics were reset at the same time. Annual emission is now under 50,000 ZET across both block types, block time is 30 seconds, and the circulating supply after the 2022 burn is approximately 59.9 million. A description that still quotes a 160 million cap is quoting the retired chain.

The client changed with it: Zetacoin Wallet is a Qt desktop application for Windows, macOS and Linux, with a data directory, a configuration file and a bootstrap option for faster first sync. That is a maintained product, not a preserved artifact.

For the background behind this step, [What Happened to the Zetacoin Swap](https://github.com/zetacoin-wallet/zetacoin-wallet-guides/blob/main/what-happened-to-the-swap.md) covers the same ground in more detail.

## Where ZET can be traded now

ZET is not on Binance, Coinbase or Kraken, and anyone claiming otherwise is either mistaken or selling something. Trading happens on smaller venues, and the list moves often enough that the only safe habit is to check the project's own exchange page at the moment you intend to trade.

The practical consequence is that liquidity is thin. Thin markets mean wider spreads and slower fills, so a large order can move the price far more than it would on a major exchange. Treat the venue list as perishable information rather than a permanent fact, and verify a pair exists before you send coins to a deposit address.

## Is the software maintained?

Yes. Zetacoin Wallet receives releases, the repository publishes build notes, and the download page on the project site presents current builds. Maintenance shows up in unglamorous ways: a bootstrap archive for faster syncing, a documented configuration file, notes about which toolchain versions break a source build.

The client is open source, so the maintenance claim is checkable rather than a press statement  -  the code, the release tags and the issue history are all visible. {{ARTICLE:who-maintains-zetacoin-now}} covers who is behind it and how to reach them, and {{ARTICLE:zetacoin-audit-open-source-status}} covers the code and audit question without overclaiming.

## How to confirm it yourself in five minutes

Install the current release, let the wallet sync, and compare its block height with a public explorer. If the numbers converge, the network is alive and your client is participating in it.

Then check three more things: that your receiving address begins with `9`, that the peer counter is above zero, and that the release you installed is the one on the GitHub releases page. Those four signals together rule out almost every false alarm, including the ones caused by an old wallet reading a retired chain.

If the wallet will not sync at all, that is a local problem rather than a network one, and {{ARTICLE:zetacoin-wallet-not-syncing-fix}} is the page for it. {{ARTICLE:why-old-zetacoin-wallet-wont-sync}} covers the specific case of a wallet that still points at the legacy chain.

## Common questions

### Is Zetacoin dead?

No. The chain produces blocks continuously, the client is maintained and released, and the network has active peers. The "dead" label comes from third-party pages written during the 2018-2021 transition and never updated.

### Did the Zetacoin blockchain ever stop?

No. Block production continued through the migration, and the current chain has run without a gap beyond normal block spacing. The retired SHA-256 chain is separate and no longer exchangeable.

### Where can I trade Zetacoin now?

On smaller venues rather than major exchanges, and the list changes. Check the project's exchange page on the day you trade, confirm the pair exists, and expect thin liquidity.

### Why do some sites say Zetacoin is inactive?

Because they have not updated a listing written before the 2021 rebuild. Their snapshot predates the Scrypt chain, the new address format and the current supply, so the status field is simply out of date.
