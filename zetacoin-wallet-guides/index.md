This repository is the front door to Zetacoin Wallet documentation. It covers the questions a reader
asks before and just after installing the client: what the chain is, which download is the real one, how the wallet file
works, how to move coins, how staking pays, and where ZET actually trades.

The guides are grouped by the job in front of you rather than by feature. The first group establishes the basics: the
chain, its maintainer, the difference between this project and ZetaChain, and the one address that publishes installers.
The second covers getting the client onto a machine and keeping the wallet file safe, which is the highest-consequence
work in the whole set. The third is the market: where ZET trades, what the price data means, and how to move coins off an
exchange without losing them.

Two rules run through every page. Nothing here asks you to send a seed phrase or a private key to anybody, and no page
promises a recovery that the software cannot perform: Zetacoin has no seed phrase, so a backup of `wallet.dat` is the
whole safety net. Every guide is written against the current release, and each one states what it cannot fix as plainly
as what it can. Verify a download by comparing its SHA-256 with the release page before you run it.
